# Gakin

사진에 날짜와 시간을 각인하는 정적 웹 앱입니다. 사진 선택부터 미리보기, 이미지 생성까지 브라우저에서 처리하며 원본 파일은 변경하지 않습니다.

**[Gakin 사용하기](https://jsha2217.github.io/Gakin/)**

## 주요 기능

- 사진 위 타임스탬프를 실시간으로 미리보고, 원하는 위치로 끌어 이동
- 클래식, 미니멀, CCTV, LCD, 필름, 포스트카드, 디지털, 투명 디지털, 스토리 손글씨, VHS, 종이 테이프 등 11가지 디자인
- 날짜·시간 직접 입력 또는 원본 촬영 시간 선택, 초 단위 표시 형식 지원
- 짧은 문구, 타임스탬프 크기, 날짜 형식, 시간대 설정
- JPG·PNG·WebP 저장과 지원 기기의 사진 공유 기능
- 기기 설정을 따르는 한국어·영어 및 라이트·다크 테마, 수동 선택 가능

## 사용 방법

1. [웹 앱](https://jsha2217.github.io/Gakin/)에서 사진을 선택하거나 카메라로 촬영합니다.
2. 날짜와 시간을 정하고 디자인을 고릅니다. 타임스탬프를 끌어 위치를 조정할 수 있습니다.
3. 문구, 표시 형식, 크기, 저장 형식을 설정합니다.
4. **타임스탬프 사진 만들기**를 누른 뒤 결과를 저장하거나 공유합니다.

## 지원 파일과 메타데이터

| 구분 | 형식 | 처리 방식 |
| --- | --- | --- |
| 입력 | JPG, PNG, WebP, HEIC/HEIF | HEIC/HEIF는 브라우저에서 열 수 있는 이미지로 변환합니다. |
| 출력 | JPG | 보이는 타임스탬프와 선택한 촬영 시간·UTC 오프셋을 EXIF에 기록합니다. |
| 출력 | PNG, WebP | 보이는 타임스탬프를 저장합니다. 촬영 시간 메타데이터는 기록하지 않습니다. |

- **원본 촬영 시간**은 JPG의 EXIF에서 읽습니다. 읽을 수 없거나 다른 입력 형식이면 파일의 수정 시간을 사용하고, 그 정보도 없으면 현재 시각을 사용합니다.
- 이미지를 새로 인코딩하므로 원본의 다른 EXIF 정보는 보존되지 않습니다. 운영체제가 표시하는 파일 생성·수정 시간도 변경하지 않습니다.
- 기기 안정성을 위해 2,000만 화소를 넘는 사진은 내보낼 때 크기를 줄입니다.
- 사진 데이터는 GitHub Pages 서버로 업로드하지 않습니다. 처리는 사용자의 브라우저에서 이루어집니다.

## 로컬 실행

별도 빌드나 패키지 설치가 필요하지 않습니다. 저장소 루트에서 정적 서버를 실행하세요.

```bash
python3 -m http.server 8765 --directory dist
```

브라우저에서 `http://localhost:8765`를 엽니다.

## 배포

`main` 브랜치에 푸시하면 [GitHub Actions](.github/workflows/pages.yml)가 `dist/`를 GitHub Pages에 배포합니다. 배포 주소는 [https://jsha2217.github.io/Gakin/](https://jsha2217.github.io/Gakin/)입니다. GitHub 저장소의 Pages 설정은 **GitHub Actions** 소스를 사용합니다.

## 파일 구성

| 경로 | 역할 |
| --- | --- |
| `dist/index.html` | 화면과 입력 요소 |
| `dist/styles.css` | 반응형 레이아웃과 테마 |
| `dist/app.js` | 미리보기, 타임스탬프 그리기, 이미지 생성 |
| `dist/exif.js` | JPG 촬영 시간 읽기·기록 |
| `dist/heic2any.min.js` | HEIC/HEIF 변환 |
| `.github/workflows/pages.yml` | GitHub Pages 자동 배포 |
